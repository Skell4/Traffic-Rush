# Traffic Rush

[![Python 3](https://img.shields.io/badge/Python-3-3776AB?logo=python&logoColor=white)](Traffic%20Rush/main.py)

An arcade game built in Python where you dodge cars in traffic, developed during a university internship.

## Description

This project was developed during a 30-hour internship at the University of Parma (Italy) in summer 2025, after the third year of high school. It is an endless runner in which you control a car and dodge traffic on a five-lane road. The longer you survive, the faster the game gets and the higher your score.

## How to Play

- Use **A/D** or the **arrow keys** to move between lanes
- Click with the **mouse** to move toward the cursor
- Avoid the cars coming from the top of the screen
- The longer you survive, the faster the game gets
- Press **ESC** to return to the menu

## Features

- **Interactive menu** with a graphical interface
- **3 difficulty levels** with different maximum speeds
- **2 player skins**
- **8 types of traffic cars**
- **Scoring system** based on distance traveled
- **Progressive speed** that increases over time
- **Accurate collision detection** between vehicles
- **Credits screen**

## Difficulty Levels

- **Easy**: maximum speed of 80
- **Medium**: maximum speed of 90, with speed increasing twice as fast
- **Hard**: maximum speed of 100, with speed increasing three times as fast

## File Structure

- `main.py` - Main game
- `g2d.py` - Graphics library by Michele Tomaiuolo (based on Pygame)
- `img/` - Sprites and graphics
