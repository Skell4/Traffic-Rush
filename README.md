# 🚗 Traffic Rush

Un gioco arcade sviluppato in Python dove devi evitare le auto nel traffico, realizzato durante uno stage universitario.

## Descrizione

Questo progetto è stato sviluppato durante uno stage di 30 ore presso l'Università di Parma nell'estate della terza superiore. Si tratta di un gioco in stile endless runner dove controlli un'auto che deve evitare il traffico su una strada a 5 corsie. Più resisti, più aumenta la velocità e il punteggio.

## Come Si Gioca

- Usa **A/D** o **Frecce** per muoverti tra le corsie
- Clicca col **mouse** per muoverti verso la posizione del cursore
- Evita le auto che scendono dall'alto
- Più duri, più aumenta la velocità
- Premi **ESC** per tornare al menu

## Caratteristiche

- **Menu interattivo** con interfaccia grafica
- **3 livelli di difficoltà** (velocità massima variabile)
- **2 skin** per il personaggio
- **8 tipi** di auto diverse nel traffico
- **Sistema di punteggio** basato sulla distanza percorsa
- **Velocità progressiva** che aumenta col tempo
- **Collisioni** accurate tra veicoli
- **Schermata credits**

## Livelli di Difficoltà

- **Facile**: velocità massima 80
- **Medio**: velocità massima 90, incremento velocità raddoppiato
- **Difficile**: velocità massima 100, incremento velocità triplicato

## Struttura File

- `main.py` - Gioco principale
- `g2d.py` - Libreria grafica (non sviluppata da me)
- `img/` - Cartella con sprite e grafica
